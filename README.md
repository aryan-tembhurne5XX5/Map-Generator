# Land Map Generator

Description:

A browser-based interactive land and site-plan generator.

Development:

npm install
npm run dev

Production build:

npm run build

Production preview:

npm run preview

Deployment:

GitHub + Vercel

## Project Structure
- `src/` - React application source code
- `dist/` - Production build output (generated)
- `public/` - Static assets

## Deployment Instructions
1. Push your code to GitHub:
   ```bash
   git add .
   git commit -m "Update Land Map Generator"
   git push
   ```
2. Vercel will automatically redeploy the application if connected to your GitHub repository.

## Environment Variables
This project currently does not require any environment variables for deployment.

## Updating the Live Site
Any push to the main branch of the connected GitHub repository will trigger an automatic build and deployment on Vercel.
